# # EPSS OTMS — System Introduction

**EPSS OTMS** (Ethiopian Pharmaceutical Supply Service – Order Tracking Management System) is a web-based platform that tracks every customer order from the moment it enters the queue until it is delivered and verified at the gate. It replaces manual paperwork with a single digital workflow, so every order has a clear owner, a clear status, and a complete history.

The system follows an **eight-stage workflow**, and each stage is handled by a specific responsible person:

1. **Queue Officer** — registers the customer and issues a queue number.
2. **Demand Management** — reviews the order and sends it to O2C.
3. **O2C Officer** — processes the order on SAP and forwards it to the EWM Focal Person.
4. **EWM Focal Person** — uploads the picklist for the warehouse team.
5. **Warehouse Operatives** — pick the items and mark the order as completed.
6. **Warehouse Manager** — creates the gatepass for the customer.
7. **Dispatcher** — verifies the gatepass and sends it to security.
8. **Security Guard** — checks the gatepass and marks the order as completed.

Each user sees only their own tasks, dashboard, and reports. **Administrators** have full control over the entire system — they can manage users, assign roles, and access every stage. Every action is logged, so the system provides full accountability and traceability.

**Key benefits:**
- No order gets lost between departments.
- Every user has a clear responsibility and limited access.
- Real-time status tracking and reporting.
- Automatic audit trail and notifications.
- Role-based security prevents unauthorized access.
